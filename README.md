# Othello Trainer Concept

A browser-based **Othello / Reversi** trainer that plays a strong game and coaches
you as you play. It's a **concept** — a real, working prototype of the right idea,
plus the documented path to true master strength.

**Just open `index.html`.** No build step, no server, no AI model, no API key.

## What it does

- You play Black; the engine plays White. The engine uses **alpha-beta search + a
  feature-weighted evaluation** — the classical approach (same family as Edax,
  Egaroucid, WZebra), **not** a neural net.
- At any of your turns, press **💡 HELP ME** to see the engine's **top-3 moves**
  with a plain-english reason for each — a fully **deterministic** coach. No LLM.
  The reason is generated by reading the eval's own feature breakdown.
- The coach also **names known tactics & openings** when the position matches —
  corner capture, wedge, Stoner trap, quiet moves, unbalanced edges, endgame
  parity, and the named openings (Tiger, Buffalo, Rose-Bill…). Consequence claims
  are verified against the engine's own search before they're shown, and every
  pick ends with an **academic reference link** (Lazard F.F.O. guide, Comte's
  strategy guide, Rosenbloom 1982, Gatliff's openings catalogue).
  The full methodology — data structures, the verification gate, the opening
  matcher, and a recipe for adding new patterns — is in
  [`docs/COACH-PATTERNS.md`](docs/COACH-PATTERNS.md), written so an AI (or
  person) can rebuild and extend the coach from scratch on their own machine.

## Why a classical engine (and why that matters for HELP ME)

Master-level Othello is a **search + evaluation** problem. The strongest engines
(Egaroucid #1, Edax ~2700, WZebra) are bitboard + alpha-beta engines, not neural
nets. This matters for two reasons:

1. **Strength and cost.** You reach master strength with zero training, no GPU, no
   inference, and no API — ideal for a browser app.
2. **Interpretability.** An evaluation function that's a weighted sum of
   *human-meaningful features* (mobility, stability, parity, corners/edge/X-squares)
   is decomposable. Each candidate move's value IS the sum of its feature
   contributions — so the coach's "why" is generated by reporting which features
   drove each move. **A neural net gives a black-box score you can't justify
   without a separate explanation model.**

## Try it

Open `index.html`, or run it from a static server:

```bash
# from the repo root
python3 -m http.server 8619
# then open http://127.0.0.1:8619/index.html
```

Play a few moves, then hit **💡 HELP ME** to see the coach's picks.

## Project layout

```
index.html        the app
style.css         UI styling
src/engine.js     board state, legal-move generation, flipping (Othello.*)
src/eval.js       feature-weighted evaluation + move decomposition (Eval.*)
src/search.js     negamax + alpha-beta + iterative deepening + the coach (Search.*)
src/patterns.js   named tactics & openings + academic citations (Patterns.*)
main.js           game controller (human vs engine), binds UI to engine
test/verify.js    Node logic tests  (node test/verify.js)
test/e2e_smoke.py Playwright smoke test against the live page
test/coach_patterns_check.py  Playwright check: insights + academic ref links
docs/ROADMAP.md   the path from here to true master level (2500+ ELO)
docs/COACH-PATTERNS.md  how the coach's patterns/openings/refs work — and how to extend them
```

## Requirements are locked

The build reflects a fully-specified design (see `requirements.md` in the
vault at `obsidian-vault/Games/Othello/`):

| Aspect | Decision |
|---|---|
| Engine strength | Master (via search + eval, not training) |
| "HELP ME" coach | Human's **top-3** moves + reason |
| Coach explanation | 2–4 sentence tactical reason (deterministic — no AI model) |
| Coach patterns | Named tactics & openings when the position matches, search-verified |
| Coach references | Every pick ends with an academic link (Lazard, Comte, Rosenbloom, Gatliff) |
| Coach availability | Every human turn, unlimited |
| Data for eval weights | WTHOR / Egaroucid labeled positions (see ROADMAP) |

## Running the tests

```bash
# end-to-end in a real browser (needs playwright + chromium)
python test/e2e_smoke.py
```
